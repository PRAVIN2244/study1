## How to Use This Course

1. **Beginners**: Start from Module 01 and progress sequentially
2. **AZ-900 Prep**: Focus on Modules 01, 02, 07, 14, 16
3. **AZ-104 Prep**: Focus on Modules 02-08, 10, 12-16
4. **AZ-204 Prep**: Focus on Modules 03, 05, 06, 09-11, 15
5. **Every module** includes: concepts, CLI commands with examples, real-world projects, common errors, and troubleshooting

## Prerequisites
- A computer with internet access
- A Microsoft account (free to create)
- Azure free account ($200 credit for 30 days)
- Basic understanding of IT concepts (helpful but not required)
