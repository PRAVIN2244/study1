## Quick Reference

| Topic | Key Takeaway |
|-------|-------------|
| **Machine Learning** | Teaching computers to learn patterns from data instead of writing rules manually |
| **Model** | A mathematical function — the output of the training process |
| **MLOps** | DevOps for machine learning — automates the ML lifecycle |
| **DevOps vs MLOps** | DevOps automates software delivery; MLOps automates model delivery. They coexist. |
| **ML Lifecycle** | Data → Train → Evaluate → Deploy → Monitor → Retrain |
