# Docker - Complete Course: Zero to Senior DevOps Architect

A self-contained, 32-module course covering Docker from absolute
beginner to expert level. Every concept is explained in depth with
commands, configuration files, diagrams, and production scenarios.

## Learning Path

```
Beginner (Modules 1-6)
  Fundamentals, installation, images, containers, Dockerfiles, Compose

Intermediate (Modules 7-12)
  Networking, volumes, projects, security basics, Swarm, optimization

Advanced / DCA Exam (Modules 13-24)
  Daemon config, content trust, secrets, namespaces, overlay networks,
  storage drivers, Raft, security deep dive, Docker Enterprise, DR,
  Kubernetes fundamentals and storage/networking

Expert / Senior DevOps (Modules 25-32)
  Docker internals, BuildKit, monitoring/observability, CI/CD,
  production patterns, debugging, DinD/rootless/Podman/Wasm,
  enterprise architecture and capstone project
```
