# GitLab Course — Basic to Advanced

A modular course covering GitLab and GitLab CI/CD from fundamentals to production-grade setups.

## Modules

| # | Module | Topics |
|---|--------|--------|
| 01 | [Introduction](module-01-introduction/) | What is GitLab, editions, DevOps platform overview |
| 02 | [Installation & Setup](module-02-installation-and-setup/) | Self-hosted install (Omnibus, Docker, K8s), initial config |
| 03 | [Architecture](module-03-architecture/) | Component architecture, Gitaly, Sidekiq, PostgreSQL, Redis |
| 04 | [GitLab CI Fundamentals](module-04-gitlab-ci-fundamentals/) | .gitlab-ci.yml, jobs, stages, variables, artifacts |
| 05 | [Pipelines](module-05-pipelines/) | Pipeline types, DAG, parent-child, multi-project, includes |
| 06 | [Runners](module-06-runners/) | Shared/group/project runners, executors, custom runners, autoscaling |
| 07 | [Advanced CI/CD](module-07-advanced-ci-cd/) | Environments, review apps, canary deployments, feature flags |
| 08 | [Security & Compliance](module-08-security-and-compliance/) | SAST, DAST, dependency scanning, container scanning, compliance |
| 09 | [Container Registry & Packages](module-09-container-registry-and-packages/) | Container registry, package registry, dependency proxy |
| 10 | [Administration](module-10-administration/) | Backup/restore, monitoring, scaling, HA, upgrades |

## Prerequisites

- Linux basics (command line, package management)
- Git fundamentals
- Basic understanding of CI/CD concepts
- Docker basics (for runner setup)
