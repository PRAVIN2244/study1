# Assignment 1 - Student Pass or Fail

Features: Study Hours, Attendance, and Previous Marks. Target: `0 = Fail`, `1 = Pass`.

The TensorFlow/Keras ANN uses normalization, two ReLU hidden layers, a sigmoid output layer, Adam optimizer, binary cross-entropy loss, accuracy metric, and 100 epochs.

```powershell
python train_model.py
streamlit run app.py
```
