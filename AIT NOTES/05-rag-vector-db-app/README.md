# Company RAG Chatbot

A small Retrieval-Augmented Generation (RAG) app that answers questions from `documents/company.txt`. It uses OpenAI embeddings for similarity search, ChromaDB as a local vector database, and Streamlit for the web interface.

## How it works

1. `ingest.py` splits `company.txt` into paragraph-sized chunks.
2. Each chunk is converted into an embedding and saved in local ChromaDB storage.
3. A user question is also embedded, then ChromaDB finds the most similar chunks.
4. The retrieved context and question are sent to the language model.
5. The model answers only from that context.

## Setup

Requires Python 3.10 or later and an OpenAI API key with billing enabled.

```powershell
cd 05-rag-vector-db-app
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Open `.env` and replace `your_openai_api_key_here` with your own key. Do not share it, and do not commit `.env`; it is ignored by Git.

`CHAT_MODEL` defaults to `gpt-4.1-mini`. If your OpenAI account uses a different supported Responses API model, change it in `.env`.

## Run

Index the document whenever you first set up the project or edit `documents/company.txt`:

```powershell
python ingest.py
```

Start the interface:

```powershell
streamlit run app.py
```

Alternatively, test from the terminal:

```powershell
python rag.py
```

## Notes

- The `chroma_db/` directory is generated locally and can be regenerated by running `python ingest.py`.
- The ingestion script recreates the collection each time, preventing duplicate chunks after re-indexing.
- For long documents, replace the simple paragraph split with a token-aware chunking strategy.
